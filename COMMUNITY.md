# Community edition (always free)

Apache-2.0. You may use, modify, and self-host everything in this repository.

**Included forever (will not be paywalled):**

- Spelling, grammar, punctuation, and clarity **rules**
- Indian English / Hinglish dialect packs that live in this repo
- Privacy / in-browser engine (`packages/engine`)
- Browser extension, VS Code extension, and desktop shell against a local or self-hosted API
- Style-as-code YAML (Vale-like) in CI and in the editor
- Public eval harness (`eval/`)
- Small from-scratch GEC checkpoints (Stage 2, ~40–80M) and the MLX trainer
- LanguageTool-shaped `POST /v2/check` compatibility

**Not included (see [ENTERPRISE.md](ENTERPRISE.md)):**

- Hosted GPU inference of larger cluster-trained weights
- Team workspaces, SSO/SAML, audit export
- Managed cloud so you do not run Docker
