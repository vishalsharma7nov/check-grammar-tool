# Quickstart — Render API + Vercel editor (~63–68% Enhanced)

Deploy **LanguageTool + Go API** on Render and the **Next.js editor** on Vercel. No paid LLM APIs. Estimated Grammarly parity: **~63–68%** (rules + LanguageTool; no cloud Ollama rewrites).

**Repo:** https://github.com/vishalsharma7nov/check-grammar-tool

Replace placeholders below with your real URLs after each deploy step.

| Placeholder | Example after deploy |
| --- | --- |
| `YOUR_RENDER_API_URL` | `https://check-grammar-api.onrender.com` |
| `YOUR_VERCEL_URL` | `https://check-grammar-tool.vercel.app` |

## Phase 1 — Render (API + LanguageTool)

### Prerequisites

- [ ] GitHub repo pushed: `vishalsharma7nov/check-grammar-tool`
- [ ] [Render](https://render.com) account (free tier for API; **starter ~$7/mo** for LanguageTool RAM)

### Step 1 — Create Blueprint

1. Open https://dashboard.render.com → **New** → **Blueprint**
2. Connect GitHub → select **`vishalsharma7nov/check-grammar-tool`**
3. **Blueprint path** — paste exactly:

```
deploy/render.yaml
```

4. Review services (should show 2):

| Service | Type | Plan | Purpose |
| --- | --- | --- | --- |
| `languagetool` | Private Service | Starter | LanguageTool on port 8010 (internal) |
| `check-grammar-api` | Web Service | Free | Go API + TS rule engine |

5. Click **Apply** and wait for both deploys (~5–15 min first build)

> **Cost note:** LanguageTool needs ≥1 GB RAM → starter plan required. API stays on free tier.

### Step 2 — Copy your Render API URL

After `check-grammar-api` is **Live**, open the service → copy the public URL from the top bar.

Paste it here for later steps:

```
YOUR_RENDER_API_URL=https://check-grammar-api.onrender.com
```

*(Use your actual URL if Render assigned a different hostname.)*

### Step 3 — Set environment variables (Render dashboard)

**Render → `check-grammar-api` → Environment → Add Environment Variable**

Add or update these (JWT_SECRET is auto-generated by the blueprint — leave it):

| Key | Value | Notes |
| --- | --- | --- |
| `WEB_ORIGIN` | `YOUR_VERCEL_URL` | Set after Vercel deploy (Phase 2). No trailing slash. |
| `API_PUBLIC_URL` | `YOUR_RENDER_API_URL` | Same as public API URL, no trailing slash |

**Copy-paste block** (edit URLs before saving):

```
WEB_ORIGIN=https://check-grammar-tool.vercel.app
API_PUBLIC_URL=https://check-grammar-api.onrender.com
```

**Already set by blueprint (do not change unless debugging):**

| Key | Value |
| --- | --- |
| `PORT` | `8080` |
| `API_ADDR` | `:8080` |
| `LANGUAGETOOL_URL` | `http://languagetool:8010` |
| `JWT_SECRET` | *(auto-generated)* |
| `CHECK_ENGINE_CLI` | `/app/server/shim/check-cli.mjs` |
| `BILLING_ENABLED` | `false` |
| `LOG_LEVEL` | `info` |
| `LLM_PROVIDER` | `local` |

Click **Save Changes** → Render redeploys the API.

### Step 4 — Verify Render (before Vercel)

First request may take **30–60 s** (free tier cold start).

```bash
curl -s YOUR_RENDER_API_URL/healthz | jq .
```

**Expected** (LanguageTool may be `false` until LT finishes warming):

```json
{
  "ok": true,
  "enhanced": {
    "languageTool": {
      "configured": true,
      "reachable": true
    }
  }
}
```

If `reachable` is `false`, wait 2–3 min and retry. If still false, check **Render → languagetool → Logs** for OOM → bump to Standard (2 GB).

Quick grammar check via API:

```bash
curl -s -X POST YOUR_RENDER_API_URL/v2/check \
  -H 'Content-Type: application/json' \
  -d '{"text":"This helllo is wrong.","dialect":"en-US"}' | jq '.issues | length'
```

Expect `1` or more issues for `helllo`.

## Phase 2 — Vercel (web editor)

### Step 5 — Import project

1. Open https://vercel.com/new
2. Import **`vishalsharma7nov/check-grammar-tool`**
3. **Configure Project:**

| Setting | Value |
| --- | --- |
| Framework Preset | Next.js |
| Root Directory | `apps/web` |
| Install Command | `cd ../.. && npm install` |
| Build Command | `cd ../.. && npm run build -w @check-grammar/web` |

*(Install/build commands are also in `apps/web/vercel.json`.)*

4. **Environment Variables** — add before first deploy (or add now and redeploy):

| Name | Value |
| --- | --- |
| `NEXT_PUBLIC_API_URL` | `YOUR_RENDER_API_URL` |

**Copy-paste:**

```
NEXT_PUBLIC_API_URL=https://check-grammar-api.onrender.com
```

Optional (default mode in UI if supported):

```
NEXT_PUBLIC_DEFAULT_MODE=enhanced
```

5. Click **Deploy** (~2–5 min)

### Step 6 — Copy your Vercel URL

After deploy, copy the production URL (e.g. `https://check-grammar-tool.vercel.app`).

```
YOUR_VERCEL_URL=https://check-grammar-tool.vercel.app
```

### Step 7 — Wire CORS (back to Render)

Return to **Render → `check-grammar-api` → Environment** and set:

```
WEB_ORIGIN=YOUR_VERCEL_URL
```

Use the **exact** Vercel URL (https, no trailing slash). Save → wait for redeploy.

### Step 8 — Redeploy Vercel (if env was added late)

If you added `NEXT_PUBLIC_API_URL` after the first deploy:

**Vercel → Project → Deployments → ⋯ → Redeploy**

Or via CLI (after `vercel login`):

```bash
cd apps/web
npx vercel env add NEXT_PUBLIC_API_URL production
# paste YOUR_RENDER_API_URL when prompted
npx vercel --prod
```

## Phase 3 — End-to-end verification

### Checklist

- [ ] `curl YOUR_RENDER_API_URL/healthz` → `languageTool.reachable: true`
- [ ] Open `YOUR_VERCEL_URL` in browser
- [ ] Switch mode to **Enhanced** (not Privacy)
- [ ] Type: `This helllo is wrong.`
- [ ] See underline on `helllo`; Accept → `hello`
- [ ] Browser devtools → Network: requests go to `YOUR_RENDER_API_URL/v2/check` (no CORS errors)

### Verification commands (copy-paste)

```bash
# 1. API health
curl -s https://check-grammar-api.onrender.com/healthz | jq .

# 2. Enhanced check endpoint
curl -s -X POST https://check-grammar-api.onrender.com/v2/check \
  -H 'Content-Type: application/json' \
  -H 'Origin: https://check-grammar-tool.vercel.app' \
  -d '{"text":"Their going to the store.","dialect":"en-US"}' | jq '.issues[].message'

# 3. CORS preflight (replace URLs)
curl -s -I -X OPTIONS https://check-grammar-api.onrender.com/v2/check \
  -H 'Origin: https://check-grammar-tool.vercel.app' \
  -H 'Access-Control-Request-Method: POST' | grep -i access-control
```

## Troubleshooting

| Symptom | Fix |
| --- | --- |
| Enhanced mode falls back to Privacy | Set `NEXT_PUBLIC_API_URL` on Vercel; redeploy |
| CORS error in browser | `WEB_ORIGIN` on Render must **exactly** match Vercel URL |
| `languageTool.reachable: false` | LT cold start or OOM — wait 60 s; check languagetool logs; bump RAM |
| API 502 / health check fail | Confirm `PORT=8080` and `API_ADDR=:8080` on API service |
| Cold start timeout | Free tier sleeps after ~15 min idle — retry after ~60 s |
| No LLM rewrites | Expected on cloud free tier — LT + rules only (~65%) |
