# Deploy Check Grammar (free tier)

Host the **Go API + TypeScript rule engine** on a free/cheap cloud service, connect the **Vercel web editor**, and optionally add **LanguageTool** for Enhanced grammar. No paid LLM APIs required.

This project is **not** affiliated with Grammarly.

## Parity vs Grammarly (realistic)

| Setup | Where | Est. parity | Notes |
| --- | --- | --- | --- |
| Privacy (in-browser engine) | Vercel only | **~50–55%** | Spelling ~370k words, rules, next-word. No LT, no rewrites. |
| API + rule engine (no LT) | Render/Fly API only | **~52–58%** | Same engine as shim; Go typo list only on API path. |
| API + LanguageTool | Render/Fly + LT (~1 GB) | **~63–68%** | Strong grammar/style; no LLM rewrites or augment. |
| Full Enhanced (LT + local Ollama) | Docker compose + host Ollama | **~70–78%** | LLM augment + rewrite panel; needs GPU/Mac host. |
| Enhanced + Ollama tunnel | Cloud API + tunneled Ollama | **~68–75%** | Dev/demo only; latency and cold starts. |

Ollama on cloud **free tier is not practical** (no GPU, RAM limits). On Render, expect **LT + rules only (~65%)** without a separate LLM.

## Architecture

```
Vercel (web editor)  ──NEXT_PUBLIC_API_URL──►  Render/Fly API (:8080)
                                                      │
                                                      ├── TS rule engine (bundled)
                                                      └── LanguageTool (private, :8010, ≥1 GB RAM)
```

LLM (optional): your Mac running `ollama` + `npm run llm:serve`, reached via tunnel or `host.docker.internal` in local Docker.

## Option A — Render (recommended free API host)

### Prerequisites

- GitHub repo pushed
- [Render](https://render.com) account (free tier for web services)
- Vercel account for the editor ([docs/vercel.md](../docs/vercel.md))

### 1. Deploy API + LanguageTool (Blueprint)

1. Render dashboard → **New** → **Blueprint**.
2. Connect this repository.
3. Set **Blueprint path** to `deploy/render.yaml`.
4. Review services:
   - `check-grammar-api` — Docker build from `server/api/Dockerfile` (free plan, 512 MB).
   - `languagetool` — `silviof/docker-languagetool` (starter plan; Java heap up to 1 GB).
5. Click **Apply**.

### 2. Set environment variables (Render → check-grammar-api → Environment)

| Variable | Value |
| --- | --- |
| `WEB_ORIGIN` | Your Vercel URL, e.g. `https://check-grammar.vercel.app` |
| `API_PUBLIC_URL` | Render API URL, e.g. `https://check-grammar-api.onrender.com` |
| `PLAGIARISM_API_KEY` | Optional — free [Winston AI](https://gowinston.ai) token enables the plagiarism/citation check |

`JWT_SECRET` is auto-generated by the blueprint. Do not commit it.

### 3. Deploy web editor on Vercel

1. [vercel.com/new](https://vercel.com/new) → import repo → Root Directory **`apps/web`**.
2. Add environment variable:

   | Name | Value |
   | --- | --- |
   | `NEXT_PUBLIC_API_URL` | `https://check-grammar-api.onrender.com` (your Render URL) |

3. Redeploy if you add the variable after the first deploy.

### 4. Verify

```bash
curl -s https://check-grammar-api.onrender.com/healthz | jq .
```

Expect `enhanced.languageTool.reachable: true` when LT is warm. Open the Vercel site → switch to **Enhanced** mode → type `This helllo is wrong.`

### Render limits (free)

| Resource | Limit |
| --- | --- |
| API web service | 512 MB RAM; spins down after ~15 min idle (cold start ~30–60 s) |
| LanguageTool | Needs **≥1 GB RAM** — starter plan; may need Standard if OOM |
| Ollama / GPU | Not supported on free tier |
| Postgres / Redis | Not included — optional for v1 checker |

## Option B — Fly.io (optional)

Good if you already use Fly credits. API fits a **256 MB** machine; LanguageTool needs a **separate 1 GB** app.

```bash
# API
fly launch --config deploy/fly.toml --no-deploy
fly secrets set WEB_ORIGIN=https://your-app.vercel.app JWT_SECRET=$(openssl rand -hex 32)
fly deploy --config deploy/fly.toml

# LanguageTool (optional second app)
fly apps create check-grammar-lt
fly deploy --config deploy/fly.languagetool.toml --app check-grammar-lt
fly secrets set LANGUAGETOOL_URL=http://check-grammar-lt.internal:8010 --app check-grammar-api
```

Set `NEXT_PUBLIC_API_URL` on Vercel to `https://check-grammar-api.fly.dev`.

Free allowance is limited; machines auto-stop when idle.

## Option C — Railway (one-click-ish)

No permanent free tier (trial credits, then ~$5/mo Hobby). See `deploy/railway.toml`.

1. **New Project** → deploy from GitHub.
2. Service 1: Dockerfile `server/api/Dockerfile`, root = repo root.
3. Service 2: Docker image `silviof/docker-languagetool:latest`, port **8010**, **≥1 GB** RAM.
4. Set env from [`.env.production.example`](./.env.production.example).
5. Connect Vercel with `NEXT_PUBLIC_API_URL`.

## Local production-like Docker

Full stack except LLM (Ollama stays on the host):

```bash
cp deploy/.env.production.example .env.prod
# Edit JWT_SECRET, WEB_ORIGIN=http://localhost:3000, etc.

docker compose --env-file .env.prod \
  -f docker-compose.yml -f deploy/docker-compose.prod.yml up --build
```

Editor: [http://localhost:3000](http://localhost:3000) with `NEXT_PUBLIC_API_URL=http://localhost:8080`.

**Full Enhanced (~70–78%)** with rewrites:

```bash
ollama pull llama3.2
npm run llm:serve          # host, port 8081
docker compose ... up      # API uses host.docker.internal:8081
```

## Ollama on cloud (dev / tunnel only)

Free hosts cannot run Ollama reliably. Options:

| Approach | Use case |
| --- | --- |
| **Rule stub** | Default when `LLM_BASE_URL` unset — deterministic typo/wordiness fixes |
| **Local Ollama + tunnel** | `cloudflared tunnel` / ngrok to `11434` or `8081`; set `LLM_BASE_URL` on API |
| **Docker compose on Mac** | `host.docker.internal:8081` — best local Enhanced experience |

Do not expose Ollama to the public internet without authentication.

## Plagiarism / originality check (optional, free tier)

`POST /v1/plagiarism` compares text against published web sources so writers can review and **cite** them (detection only — nothing here evades detectors). Without a key it returns `200` with `skippedReason: "no provider configured"`, so it is safe to leave unset.

| Variable | Value |
| --- | --- |
| `PLAGIARISM_API_KEY` | API token from your provider |
| `PLAGIARISM_PROVIDER` | `winston` (default when only a key is set), `prepostseo`, or `generic` |
| `PLAGIARISM_API_URL` | Only for `generic` (or to override a provider endpoint) |

**Free key (Winston AI):** register at [gowinston.ai](https://gowinston.ai) → free API credits at signup, no credit card → dashboard → API tokens. Plagiarism checks cost 2 credits/word, so free credits cover roughly a thousand words of checking — fine for trials; add credits for production. Set the variable on your API host (Render/Fly/Railway env, or `.env` locally) and restart.

## LanguageTool RAM

The bundled LT image defaults to **512m–1g Java heap**. Allocate **at least 1 GB** container memory (1.5 GB recommended). Symptoms of under-provisioning: OOM kills, `/healthz` shows `languageTool.reachable: false`.

## Troubleshooting

| Symptom | Fix |
| --- | --- |
| Enhanced mode falls back to Privacy on Vercel | Set `NEXT_PUBLIC_API_URL`; redeploy Vercel |
| CORS error in browser | `WEB_ORIGIN` on API must exactly match Vercel URL |
| `languageTool.reachable: false` | LT cold start or OOM — check Render/Fly logs; bump RAM |
| Cold start timeout | Render free tier wakes on first request — retry after ~60 s |
| Rewrites 502 | No LLM on cloud — expected unless you tunnel Ollama |
