Check Grammar

This overlay checks as you type in text fields (Mail in the browser, Slack web, LinkedIn, this editor). Sentence structure, spelling, and next-word chips stay on this computer.

  1. Keep this extension enabled.
  2. Click a text box and pause briefly — underlines and a card appear.
  3. Tab inserts the first next-word chip.

Native Mac apps (Notes, Mail.app) cannot be read without Accessibility. Type in the live pad or in the browser.

Google Docs is unsupported. Not affiliated with Grammarly.
