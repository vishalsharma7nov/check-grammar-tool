# Security policy

## Supported versions

The `main` branch and the latest tagged release receive security fixes.

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Email **security@example.com** (replace with a real address before public launch) or use GitHub private vulnerability reporting.

Include:

- A description of the issue
- Steps to reproduce
- Affected version / commit
- Whether user text can leave the device unexpectedly (privacy bugs are security bugs)

We will acknowledge receipt within 7 days.
